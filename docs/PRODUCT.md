# Bilgarasje — Product Doctrine

## Nordstjerne
**Interesse først. Struktur seinare.**

## Kjernepåstandar
1. Ein bil eksisterer når nokon dokumenterer den.
2. Posting er fødselen til objektet — ikkje slutten på flyten.
3. Metadata blir discovery, ikkje administrasjon.
4. Offentleg sannheit: `/biler/:slug`. Dashboard = verkstad.
5. Spotting publiserer bilen (også ved match på upublisert bil).
6. Éin brukarintensjon: «Eg vil dele denne bilen.»

## Livssyklus
interesse → publisering → discovery → struktur

## Beslutningsfilter
- Respekterer øyeblikksenergien (bilde → publiser)?
- Får objektet URL med ein gang?
- Er metadata valfri oppfølging?
- Peikar alt offentleg til `/biler/:slug`?

## Anti-mønster
- Metadata som inngangsbillett
- Spotting vs «send inn» som to sannheiter
- Dashboard som «der bilen blir ekte»
